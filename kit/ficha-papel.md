# Ficha de papel: registro de autonomia

Imprima, cole na parede, marque a cada tarefa que a IA fizer. Uma linha por tarefa (não por conversa).

| Data | Tarefa (verbo + objeto) | Nível 0-4 | Conexão usada | Fez sozinha? | Precisou corrigir? (S/N) | Repetição (1ª, 2ª, 3ª...) |
|---|---|---|---|---|---|---|
| | | | | | | |

## Como marcar o nível
- **0** só respondeu. **1** montou rascunho/plano, eu apliquei. **2** fez, mas eu aprovei cada passo.
- **3** fez sozinha e me avisou. **4** rodou o processo inteiro e só me chamou na exceção.

## Conexão usada
Escreva o nome do que a IA tocou: pasta, planilha, e-mail, agenda, site, banco de dados, rede social, outro programa. Toda conexão nova é uma porta nova: anote a data da primeira vez.

## Fechamento da semana (5 minutos)
1. Conte quantas linhas de cada nível.
2. Procure tarefa que apareceu 3+ vezes no nível 0 a 2: é candidata a subir.
3. Procure tarefa nível 3 ou 4 que precisou de correção mais de 1 vez em 10: desça um nível.
4. Liste conexões novas da semana. Alguma você não lembrava de ter liberado?
